# 種別D: 性能・リソース

共通ルール（編集禁止・根拠と確度・サブエージェントの扱い）は `flows/investigate/SKILL.md` に従う。

```
1. 計測手段を決める（実行時間・ログ・プロファイラ・クエリ数・ブラウザのパフォーマンス計測等）
   - コマンドは、プロジェクトの CLAUDE.md / README に書かれた起動・テストコマンドを使う
   - 計測がローカルのデータを変更しうる場合は、SKILL.md のルール「データを変更しうる実行」に従う

2. 先に現状値（ベースライン）を取る

3. 仮説ごとに計測し、ベースラインと比較して、遅い・重い箇所を切り分ける
   - 計測のためにソースを書き換えない（必要なら一時コピーで行い、調査後に自分が作成したコピーだけを削除する）
```
