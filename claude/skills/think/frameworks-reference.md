# 思考・分析フレームワーク一覧（参照用）

think の8カテゴリ（dialogue / structure / root-cause / decide / six-hats / idea / reflect / triz）でしっくりこない時に、他の切り口を探すための一覧。

ここに載っている手法の大半はサブスキルとして実装されていない。気になる手法があれば「〇〇の考え方で整理して」とそのまま伝えれば、その場で適用できる。`→ /think <スキル名>` の注記があるものは think のサブスキルとして実装済み。

---

## 経営戦略

- **企業ピラミッド（ビジョン・戦略・オペレーション）**: 経営意思から現場までの一貫性を構築する
- **デルタモデル**: 戦略立案から実行まで、企業の戦略を練る
- **PEST分析**: 経済・社会・技術・法規制など外部環境を分析する
- **3C分析**: 顧客・競合・自社の3視点から成功要因を探る
- **SWOT分析**: 自分や自社の強み・弱み・機会・脅威を分析する
- **リソース・ベースド・ビュー／VRIO分析**: 経営資源の価値をチェックする
- **バランススコアカード**: 財務・顧客・業務・学習の4視点で戦略の実行度を整理する
- **5F（5つの競争要因）**: 業界の魅力度・競争構造を分析する
- **ランチェスターの法則**: 弱者の戦略・強者の戦略を使い分けて勝つ
- **コトラーの4つの競争地位分類**: 業界における地位でプレイヤーを分類する
- **アンゾフの成長マトリックス**: どのような成長戦略を採用するか検討する
- **PPM（プロダクト・ポートフォリオ・マネジメント）**: 花形・お荷物など事業の位置づけを見極める
- **バリューポートフォリオ**: 注力すべき事業や商品を見極める
- **アドバンテージマトリックス**: 業種ごとの競争優位性の作り方を分析する
- **ビジネススクリーン**: 成長率とシェアから事業ポートフォリオを評価する
- **シナリオ・プランニング**: 多様な未来を想定して戦略を策定する
- **ブルーオーシャン戦略**: 血の海（競争）を避け、戦わずして勝つ
- **バリューイノベーション／ERRC**: 低コストと高付加価値を同時に実現する
- **戦略キャンバス／価値曲線**: メリハリ戦略で競合と戦わずに勝つ
- **6つのパス**: 市場の境界を引き直すヒントを得る
- **コア・コンピタンス分析**: 他社にはない自社の強みを客観的に計測する
- **ポジショニング戦略**: 業界の競争状態に応じて戦略を選ぶ
- **損益分岐点分析（CVP分析）**: 利益と損失の分岐点をシミュレーションする
- **財務諸表三表（B/S、P/L、C/F）**: 1分で読める企業の通信簿を読み解く
- **財務諸表分析（比率分析）**: 財務の健全性を比率で把握する

## カイゼン・時間管理

- **PDCA**: 計画・実行・評価・改善の好循環サイクルを回す
- **OODAループ**: 観察・情勢判断・意思決定・行動で迅速に適応する
- **ペイオフマトリクス**: コスパ（費用対効果）で施策の優先順位を決める
- **5S／カイゼン（Kaizen）**: 継続的改善で効率と品質を高める
- **ジャストインタイム（JIT）**: 無駄なく効率的な生産を実現する
- **ダブル・ダイヤモンド・デザイン・プロセス**: 発散と収束を2度繰り返して解決策を導く
- **成熟度モデルの6段階**: 業務のマニュアル化度合いで組織の強さを測る
- **フィッシュボーンチャート／特性要因図**: 原因と結果の関係性を明確にする
- **PERT図（パート図）／アローダイアグラム**: クリティカルパスを発見し遅れを防ぐ
- **バリューチェーン**: どのプロセスに競争優位性があるかを発見する
- **デコンストラクション**: バリューチェーンを再構築して独自性を出す
- **サービスプロフィットチェーン**: 顧客も従業員もみんなハッピーにする好循環を作る
- **ハインリッヒの法則／1:29:300の法則**: 1件の重大事故の背後にある多数の予兆に気づく
- **チクセンミハイのフロー理論**: 没入体験が導く最高のパフォーマンスを理解する
- **インフルエンス・ダイアグラム**: 要素間の影響具合を関連づけて整理する
- **経験曲線（エクスペリエンスカーブ）**: 生産量・習熟度でコストが下がる仕組みを捉える
- **シックスシグマ**: 統計的手法で品質のばらつきを徹底管理する
- **SIPOCダイアグラム**: 供給者・入力・工程・出力・顧客で業務プロセスを可視化する
- **TOC（制約条件の理論）／DBR（ドラム・バッファー・ロープ）**: ボトルネックに全体を合わせて最適化する
- **時間管理のマトリックス**: 重要度×緊急度で優先順位をつける
- **GTD（Getting Things Done）**: ストレスフリーのやらなきゃリストを整理する
- **ポモドーロテクニック**: ダラダラやらず短時間集中で効率を最大化する
- **タイムブロッキング**: 業務プロセスをブロックごとに可視化して時間管理する
- **1万時間の法則**: 熟練にはそれなりの時間が必要と心得る
- **逆算思考（バック・キャスティング）**: 目標達成への最短距離を未来から逆算して描く

## 製品開発・マーケティング

- **プロダクトアウト／マーケットイン**: 製品中心か市場中心か、戦略の分かれ道を見極める
- **TAM、SAM、SOM**: 市場ポテンシャルを段階的に把握する
- **STP（Segmentation, Targeting, Positioning）**: 市場を細分化し、狙いを定め、位置づける
- **マーケットセグメンテーション**: 自社の狙うターゲットを特定する
- **マーケティングミックス（4P、4C）**: 売れる仕組みをつくる実行プロセスを組み立てる
- **プロモーションミックス**: 商品を知ってもらうベストな組み合わせを選ぶ
- **ポジショニングマップ**: 顧客にとっての自社商品の立ち位置を可視化する
- **パレートの法則（80対20の法則）**: 売上の8割は2割の売れ筋商品から生まれると捉える
- **ロングテール理論**: オンライン販売では売れ筋以外の重要性に注目する
- **PLC（プロダクトライフサイクル）**: 製品の寿命はいつまでかを見極める
- **イノベーター理論**: 新製品が市場に受け入れられるプロセスを分析する
- **AIDMAの法則**: 消費行動の基本プロセスを理解する
- **AISAS理論**: 現代の消費行動は検索（Search）と共有（Share）で動くと捉える
- **購買行動の4要因**: 成功するマーケティングのために購買者の特性を把握する
- **需給曲線**: 市場価格がどう決まるのかを理解する
- **PSM分析（価格感度分析）**: 儲かる・売れる新商品の適正価格を決める
- **1:5の法則／5:25の法則**: 既存顧客に手厚くすれば利益も大きいと捉える
- **フックモデル**: ユーザーを虜にする科学的サイクルを設計する
- **サービス・ブループリント**: サービスの全体像を可視化する設計図を描く
- **ネットプロモータースコア（NPS）**: 顧客ロイヤリティを数値化して戦略を磨く
- **リーンキャンバス（The Lean Canvas）**: 事業計画作成前にビジネスモデルをシンプルに可視化する
- **SPIN式営業話法（SPIN Selling）**: 効果的な販売対話のための技術を使う
- **バリュー・プロポジション・キャンバス（VPC）**: 顧客のニーズに応える価値を設計する
- **デザイン思考**: ユーザー中心の視点による創造的解決を目指す
- **MRR／チャーン分析・LTV/CAC比率**: サブスクビジネスの健全性を数値で把握する

## アイデア発想・論理思考

- **MECE（ミーシー）**: モレなく、ダブりなく、問題を整理する → /think structure
- **仮説思考**: 未知の物事を予測し、事件を解決するように考える
- **5W1H（または5W2H）**: プロジェクトの要件を整理する → /think idea
- **5つのWhy？**: 問題の根本原因を探る深掘りをする → /think root-cause
- **オズボーンのチェックリスト／SCAMPER**: 新しい視点でアイデアを転換してみる → /think idea
- **KJ法**: カードを動かす古典的アイデア発想法 → /think idea
- **マインドマップ**: 脳内地図をグラフィック化する発想法
- **Pros Cons（プロ・コン）リスト**: 選択肢の良い面と悪い面を整理する → /think decide
- **フェルミ推定**: 複雑な問題をシンプルに考える推定技術を使う
- **逆設定法（逆転の発想）**: 既成概念を覆し新たな視点を開く
- **KISSの法則（Keep It Short, Simple）**: 単純明快、効率の良さを追求する
- **創造性を妨げる6つのメンタルバリア**: 自由なアイデアづくりを阻害する壁を自覚する
- **ワラスの4段階**: 創造的発想のプロセスを明確にする
- **ヤングのアイデア生成の5段階**: 創造性を育む段階的プロセスをたどる
- **ロジックツリー／ピラミッドストラクチャ**: 論理的に考え、相手に説明する → /think structure
- **ブレインストーミング／ブレインライティング**: アイデア創出のための集団的思考法を使う → /think idea
- **連想の4法則**: 思考の連鎖を活用した創造的発想をする
- **SUCCESSsの法則**: 記憶に焼きつくメッセージが持つ6つの要素を意識する
- **ゴールデンサークル理論**: 「なぜ」から始めて戦略を策定する
- **プレゼンオーディエンス分析**: 聴衆を知らずしてプレゼンはできないと心得る
- **10:20:30の法則**: Appleが認めた効果的なプレゼンテーションの公式を使う
- **As Is / To Be**: 「現状」と「あるべき未来」のギャップを認識する
- **TRIZ（トゥーリーズ：発明的問題解決）**: 革新的な解決策に共通点を見出す → /think triz
- **創造的問題解決フレームワーク（CPS）**: 創造的思考による問題解決を体系立てる
- **マンダラート**: 大谷翔平も実践したアイデア創出法を使う

## 組織・人事評価

- **マズローの欲求階層説**: 欲求のレベル理解による効果的な行動促進を図る
- **ハーズバーグの二因子理論**: モチベーションと満足度の違いを理解する
- **タックマンのチーム発達モデル**: チーム成長の5ステップを捉える
- **ジョハリの窓**: 自分から見た自分と他人から見た自分を整理する
- **状況的リーダーシップ理論（SL理論）**: 部下の成熟度に合わせた適切な指導スタイルを選ぶ
- **7S戦略**: 強い組織を作るためのソフト＆ハード戦略を整理する
- **ADKAR変革管理モデル**: 組織が変化を受け入れるための5ステップを踏む
- **組織文化の4分類**: 捉えどころのない組織文化を4象限で分析する
- **フライホイール**: 持続的成功のための加速化メカニズムを回す
- **ステークホルダーマップ**: 利害関係者の影響と関心を可視化する
- **4つの組織戦略**: 事業や企業の課題・成長に合わせた道筋を選ぶ
- **MBO（Management by Objectives）**: 目標設定で組織を動かす
- **スマートの法則（SMART Criteria）**: 実現可能な目標設定の5原則を満たす
- **360度評価**: 全方位からの評価で成長を促進する
- **コンピテンシー・ベースド評価**: 能力中心の評価で人材を育成する
- **OKR（目標と主要成果）**: 目標達成のための具体的なステップを設計する
- **KPI（Key Performance Indicator）**: 目標達成への道しるべを設定する
- **スタックランキング／ランク・アンド・ヤンク**: 従業員評価の切り札、成果主義の極みを知る
- **行動基準評価スケール（BARS）**: 実際にどう動いたかで人材を評価する
- **9ボックスグリッド**: 才能を管理するための戦略的マトリックスを使う
- **クリティカル・インシデント・テクニック（CIT）**: 重要事象から学ぶ組織の教訓を集める
- **マネジメント・バイ・ウォーキングアラウンド（MBWA）**: 歩くことで経営を見守る
- **KPT（Keep, Problem, Try）**: 経験から学び、成長へと導く反省会をする → /think reflect
- **ミッション、ビジョン、バリュー（Mission, Vision, Value）**: 組織の指針、未来への羅針盤を定める
- **ワールドカフェ**: リラックス対話による創造的知識共有を行う
