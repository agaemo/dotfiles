# タイポグラフィ

エンジニア向けの対応: タイプスケール = 命名された定数の集合。サイズをその場で決めず、スケールから選ぶ。

## 原則

- 階層は「サイズ・ウェイト・色(濃さ)」の差で作る。サイズだけに頼らない。同一サイズでもウェイトと色で差は出せる
- 1つの画面で使うサイズは**5〜7段階**まで。増やすほど階層が読めなくなる
- 差は十分に付ける。隣り合う段の比が 1.2 未満だと「違い」ではなく「ズレ」に見える
- フォントファミリーは**原則2つまで**（見出し用 + 本文用）。業務系は1つで十分

## 既定のタイプスケール（比率 1.25 前後、基準 16px）

| 名前 | サイズ | 用途 |
|------|-------|------|
| xs | 12px | 注釈・キャプション（最小。これ未満は避ける） |
| sm | 14px | 補助テキスト（デジタル庁DSは本文・UIに 14px を基本使わない。高密度の業務画面のみ） |
| base | 16px | 本文 |
| lg | 20px | 小見出し |
| xl | 24px | 見出し |
| 2xl | 32px | ページ見出し |
| 3xl | 40〜48px | LPのキャッチ（表現重視ならさらに大きく） |

LP・ブランドサイトでは、最大サイズを本文の **4〜6倍**（64〜96px）まで上げて「スケール差」で印象を作る手法がある（`expression.md` 参照）。

## 行間・行長・字間

- 本文の行間（line-height）: デジタル庁DSは**本文で少なくとも 1.5 倍**、一般的な本文は **1.7（170%）前後**を採用。業務画面は 1.2、管理画面は 1.3 の密なスタイルも定義（`ja/typesetting.md`）。1.5 未満の本文は WCAG 1.4.12 の観点でも避ける
- 見出しは行間を詰める: 1.2〜1.4（大きいほど詰める）
- 1行の長さ: 欧文は 45〜75文字、和文は 35〜45文字が読みやすい目安とされるが、**出典未確認の経験則**（JLReq は、行長を文字サイズの整数倍に設計すると述べる程度）。長文は `max-width: 40em` 程度で制限する
- 字間（letter-spacing）: 大きい見出しは少し詰める（-0.01〜-0.03em）、小さい大文字（英字ラベル）は広げる（0.05〜0.1em）。和文の見出しは `0.02〜0.05em` 広げると上品に見えることがある
- 和文の本文は `font-feature-settings: "palt"`（プロポーショナルメトリクス）を見出しに使うと詰まって読みやすい。本文には通常使わない

## ウェイト

- 通常は 400（本文）/ 500〜600（強調・ラベル）/ 700（見出し）の3段階で足りる
- 全要素が同一ウェイトだと階層が出ない。見出しは太く、補助は細く
- 細いウェイト（300以下）を小さい文字や暗い背景で使うと読めなくなる。避ける

## 和文フォント選定

システムフォント頼みだと「AIのデフォルト」に見えやすい。ただし、読みやすさ・表示速度と引き換えであることを理解して選ぶ。

| 印象 | 候補 | 備考 |
|------|------|------|
| 標準・中立 | Noto Sans JP | Google Fonts。ウェイト豊富。サブセット化されるが読み込みは重め |
| 丸み・親しみ | Zen Maru Gothic / M PLUS Rounded 1c | Google Fonts |
| 現代的・端正 | Zen Kaku Gothic New / BIZ UDPGothic | Google Fonts |
| 上品・信頼（セリフ） | Noto Serif JP / Shippori Mincho / Zen Old Mincho | Google Fonts。見出し向き |
| 個性的 | Dela Gothic One / Reggae One / Yusei Magic | 見出しのみ。本文には不向き |

- 上記は Google Fonts での配布を前提とした候補。実際に使う際は、ライセンスと配布状況を公式で確認する（変更されることがある）
- 欧文はプロダクトの個性に合わせて別に選ぶ（例: Inter 以外にも、DM Sans / Manrope / Space Grotesk / Fraunces / Playfair Display など）
- 和欧混植は、欧文を和文フォントより**やや小さく見える/揃う**ものを選ぶ。`font-family` は欧文を先に書くと欧文だけ差し替えられる
- フォントは読み込みコストが大きい。**使うウェイトは2〜3個に絞り**、`font-display: swap` を指定する

## 数字と等幅

- 表・金額・日時の数字は `font-variant-numeric: tabular-nums` で桁を揃える（業務系では必須級）
- コード・ID は等幅フォント

## よくある失敗

- 見出しと本文のサイズが近く、階層が弱い
- 本文が 16px 未満（デジタル庁DS は 16px 以上を基準とする）
- 和文本文の行間が 1.5 未満で詰まって見える
- 行長が長すぎる（和文で60文字超）
- 太字を多用して、何が強調か分からない
