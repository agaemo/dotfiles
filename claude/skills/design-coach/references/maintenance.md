# references の追記・修正のルール

このスキルの知識（`references/`）を更新するときに従う。更新前に、変更内容を示してユーザーの了承を得る（`SKILL.md` の共通原則）。

- 判断できなかった場面や回答が弱かった場面は、`references/gaps.md` への追記を提案する
- 出典は**公式・一次**（W3C、NN/g、MDN、デジタル庁、Carbon、GOV.UK など）の**名前だけ**を書く。URL、取得日、第三者の記事・個人のメモは書かない（トークンの節約）
- 出典が食い違うときは、両方を示し、統合した結論には「私の統合」と明記する
- 数値は、出典にあるものだけを書く。ないものは「経験則」と明記する
- `gaps.md` には**未対応の不足だけ**を1行で書く。対応済みの行や日付は残さない
- 新しい説明表（エンジニア向け対応など）は、判断に役立つものだけにする
- 追記・修正したら、`references/INDEX.md` の該当行（いつ読むか、◎○△の状況）も更新する
