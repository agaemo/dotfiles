# 素材・フォント・できること/できないこと

上級デザインの品質の相当部分は、このスキルの外（素材・ブランド資産・ライセンス）にある。**期待値のずれを防ぐため、最初に正直に伝える。**

## このスキルが担えるもの

- 構成・階層・余白・タイポ・色の判断と、その理由の説明
- 方向性の複数案のモック（HTML）と比較
- トークンとデザインシステムの仕様化（craft 形式）
- 既存画面の批評と修正指示
- 参考サイトの分解と、再現できる層の仕分け
- 「整っていて、無難でなく、一貫している」水準

## このスキルでは担えない（または限定的）

| 領域 | 理由 | 代替 |
|------|------|------|
| 写真・動画の撮影/アートディレクション | 素材が品質を左右する | ユーザーが用意、またはタイポ主体・図形・イラストで設計する |
| ロゴ・CI/VI の制作 | ブランド資産の制作はユーザー（デザイナー）の領域 | 方針と要件の整理までを支援し、制作は人に任せる |
| 商用書体（Helvetica Now、Tazugane Gothic 等） | ライセンスが必要 | Google Fonts 等の無料書体で近づける。商用書体を使う場合はユーザーがライセンスを用意 |
| 精緻なモーション/WebGL | 実装コストが高く、検証が必要 | 代表的な動き1〜2個に絞る。複雑なものは仕様化して実装側へ |
| 実機・実ブラウザでの最終検証 | 環境依存 | スクリーンショットで複数幅を確認し、残りはユーザーが実機で確認 |
| 人による審美眼の最終判断 | 好みの要素が大きい | 複数案を理由つきで提示し、ユーザーが選ぶ |

## 最初に確認すること（素材が品質を左右する案件）

- 写真・動画・イラストは用意できるか（枚数、質、権利）
- ロゴ・ブランドカラー・既存のガイドラインはあるか
- 使ってよいフォントの範囲（無料のみ / 商用ライセンスあり）
- 実装工数の上限（モーションの作り込みにどこまで使えるか）

用意できない場合は、**タイポ・色・余白・図形だけで成立する設計**（編集的・タイポグラフィ主体）に寄せる。写真に頼る設計は、素材がないと一気に安く見える。

## フォントのライセンス

- Google Fonts（SIL OFL など）は商用利用できるものが多いが、**個別の書体のライセンスを公式で確認する**
- 商用書体は、サブスクリプション型の配信サービス、または買い切りの Web フォントライセンスが必要
- 日本語 Web フォントは容量が大きい。サブセット化・必要なウェイトの絞り込み・`font-display: swap` を指定する

## 画像の扱い

- 解像度: 表示サイズの2倍（Retina）を目安に用意し、`srcset` / モダン形式（WebP / AVIF）で配信
- 色調: 同じページの画像は、トーンを揃える（色補正、デュオトーン、オーバーレイ）
- 文字を重ねる場合は、コントラストを確保（オーバーレイ、位置調整）
- ストック素材は、ライセンス条件（商用可否、クレジット表記）を確認する

## 期待値の伝え方

大規模ブランドサイト（例: コクヨ）のような水準を求められたら、次の形で伝える。
1. 再現できる層（構成・余白・タイポ・色・抑制の作法）と、できない層（素材・CI・作り込みのモーション）を仕分ける
2. 「同じものにはならないが、**方向性と品質の下限を引き上げる**ことは可能」と説明する
3. 差を埋めるために、ユーザー側で用意が必要なもの（素材、ブランド資産、ライセンス）を挙げる
