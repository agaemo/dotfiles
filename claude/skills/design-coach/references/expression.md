# 表現手法（LP・ブランドサイト・マーケティング寄り）

業務系は「処理させる」画面、LP・ブランドは「印象づける」画面。後者は**情報密度を下げ、1画面1メッセージ**にして、スケール差・余白・色・写真で語る。

## 構成の基本（LP）

1. ファーストビュー: キャッチコピー（何を・誰に）、補足1文、CTA1つ、ビジュアル。**スクロールなしで価値が伝わる**ことを最優先
2. 課題の提示 / 共感
3. 解決策・特徴（3〜4点。数を増やさない）
4. 根拠（実績・数字・事例・声）
5. 料金/進め方（必要なら）
6. 最終CTA（ファーストビューと同じ行動を再提示）

- CTAの文言は動詞+メリット（「無料で試す」「資料を受け取る」）。「送信」「こちら」は避ける
- 各セクションに**1つの見出し+1つの主張**。セクションの背景色や余白を変えて区切りを明示する

## 印象を作る手法

| 手法 | 効果 | 注意 |
|------|------|------|
| **スケール差**（巨大な見出し vs 小さな本文） | 力強さ・編集的な印象 | 本文の可読性は保つ。差は4倍以上が目安 |
| **余白の贅沢な使い方** | 高級感・静けさ | 上下のセクション余白を 96〜160px に |
| **非対称・グリッド崩し** | 個性・動き | 基準線は残す。崩しすぎると雑に見える |
| **モノトーン+1アクセント** | 洗練・集中 | アクセントを10%以下に |
| **大胆な背景色/ベタ面** | 印象の強さ | 文字のコントラストを再確認 |
| **セリフ体の見出し** | 上品・信頼・文化的 | 本文はサンセリフとの組合せが安全 |
| **大きな写真/イラスト** | 感情・世界観 | 写真の質が全て。素材が弱いならタイポ主体に |
| **細い罫線・グリッドの見える化** | 知的・建築的 | 線の太さは1px、色は薄く |
| **マイクロインタラクション** | 触感・上質さ | 後述 |

## 世界観の作り方

1. FEEL 3語 / ANTI-FEEL 3語を決める（例: FEEL=静か・精密・誠実 / ANTI-FEEL=派手・軽い・騒がしい）
2. 語からアーキタイプ（`design-brief.md` テンプレートの表）を1〜2個選ぶ
3. 色・タイポ・形・密度・余白をその語に合わせる。**全ての選択が同じ語を指している**状態が一貫性になる
4. 他のサイトを**1〜3個**参照し、好きな「要素」（余白、タイポ、色）を分解して抽出する。丸ごと真似ない

## 画像・素材

- 素材が弱いと全体が安く見える。**質の低い写真は使わない**方がよい
- ストック写真を使う場合は、色調補正で全体の色味を合わせる（デュオトーンやオーバーレイ）
- 代替: イラスト、抽象的な図形、グラデーション、大きなタイポ、プロダクトのスクリーンショット
- **製品の画面は、HTML + CSS で再現して見せられる**（スクリーンショットがなくても作れる）。装飾として扱い `aria-hidden`、意味は隣の見出し・説明が担う。状態は色だけでなく記号と文字でも示す。機能ごとに1つの断片を対にすると、左右交互の配置が成立する
- 画像にテキストを重ねるときは、オーバーレイでコントラストを確保する。実画像を載せたときは、文字のコントラストを実測し直す（モックの想定値は確定値ではない）

## LP の部品の判断（経験則）

- **ダーク/ライトの手動切替は、LP では原則不要。** LP は広告の見た目と揃え、1回の訪問で行動させる画面。両テーマ対応は設計・実測・テストが倍になる。手動切替はアプリ・管理画面・ドキュメント向け
- **広告LPは、ヒーローと最終CTAを「面」で強くする**（常に暗い面、琥珀などのベタ）。強さは文言（点滅・「今だけ」・カウントダウン）でなく、サイズ・色の面・数字の大きさで出す
- **実績の数字（件数・短縮時間など）は、根拠と算出条件を添える。** デザインの検証用に仮の数字を置くときは「架空」と明記する（景品表示法に関わる領域）
- **料金の比較表は、スマホで横スクロールにしない。** PC は `table`、スマホはプランごとの縦リストへ折りたたむ（WCAG 1.4.10）。おすすめ列は色 + 「おすすめ」の文字で示す

## モーション（控えめに）

- 目的: 状態の変化の理解、注意の誘導、触感。**装飾のためだけに動かさない**
- 時間: 小さな変化 150〜200ms、画面内の移動 250〜400ms。イージングは ease-out（出現）/ ease-in（退場）
- 定番: ホバーでの色/影の変化、スクロールでのフェードイン（1回だけ、移動量は小さく 12〜24px）、ボタン押下の沈み込み
- 過剰なパララックス・自動再生アニメーションは酔いや読み込み負荷の原因。避ける
- `prefers-reduced-motion` を尊重する（動きを減らす設定の人には止める）

## 業務系との切り替え判断

| 観点 | 業務系 | LP・ブランド |
|------|-------|-------------|
| 目的 | 正確・効率的に処理 | 印象づけ・行動を促す |
| 密度 | 高い | 低い |
| 装飾 | 最小限 | 世界観に必要な分だけ |
| 色 | 役割の一貫性 | 感情・記憶に残る色 |
| 余白 | 詰め気味(8〜24px) | 広く(48〜160px) |

同じプロダクトでも、管理画面とマーケティングページで密度と装飾を切り替えてよい。ただし**色・フォント・角丸などのトークンは共通**にしてブランドの一貫性を保つ。

## よくある失敗

- 情報を詰め込みすぎて、何が言いたいか分からない
- 特徴を6個以上並べ、どれも印象に残らない
- キャッチが抽象的（「新しい体験を」）で、何のサービスか分からない
- CTAが複数あり、競合している
- 素材が弱いのに画像に頼る
