# アンチジェネリック（AIっぽさ・テンプレ感の回避）

AIが出しやすい「無難な既定値」を、意図なく採用していないかを点検する。**理由があれば採用してよい**。問題は「理由なく既定になっていること」。

## チェック表

| 領域 | 問題のパターン | 改善の方向 |
|------|--------------|-----------|
| カラー | 理由なき青系プライマリ(#3B82F6 等)・純グレー(#F3F4F6 / #6B7280 等)のみ | 業種/世界観から色を導出し、ニュートラルもアクセントの色相に寄せる |
| カラー | 紫〜青のグラデーション背景 | 単色+淡いトーン差、または世界観に合う別の配色 |
| タイポ | Inter / システムフォントのみ、全要素が同一ウェイト | 見出し用フォントを分ける、ウェイト差とサイズ差で階層を作る |
| タイポ | 見出しと本文のサイズ差が小さい | スケール差を広げる |
| レイアウト | 均等な3カラムの同サイズカード | サイズ差、非対称、交互配置 |
| レイアウト | 全セクションが「見出し+カード3枚」の繰り返し | セクションごとに構図を変える |
| レイアウト | 全てを中央揃え | 左揃えを軸にし、中央揃えは短い見出し/CTAのみ |
| 装飾 | 全カードに同じ角丸+影 | 面の色差と余白でグルーピング、影は階層を表す時だけ |
| 装飾 | 絵文字や汎用アイコンを見出しの飾りにする | アイコンは意味がある時だけ。ライブラリを統一 |
| 文言 | 抽象的なキャッチ（「次世代の」「シームレスな」） | 具体的な価値・数字・対象に置き換える |
| 画像 | 汎用ストック写真 | 色調を揃える/イラスト/プロダクト画面/タイポ主体 |

## 点検の手順

1. 画面を見て「どのプロダクトでも通用する見た目か」を自問する。他のサイトにそのまま置けるなら汎用的すぎる
2. 上の表の各行について、**該当しないか**を確認する
3. 該当する場合は「意図的か」を確認する。意図があれば理由を記録して維持、なければ改善案を出す
4. 改善は**1〜2点に絞って変える**。全てを変えると統一感を失う。最も効果が大きいのは通常、**色・見出しのフォント・スケール差**の3点

## 個性を出す優先順位

1. 見出しのタイポ（フォント選択とスケール差）
2. アクセント色とニュートラルの色味
3. 余白の取り方（広さ・リズム）
4. 構図（非対称・サイズ差）
5. 細部（アイコン、角丸、罫線、モーション）

## 注意

- 個性を優先して**可読性・コントラスト・操作性を犠牲にしない**
- 業務系では、個性より一貫性が優先。アンチジェネリックは「色味・フォント・余白」の3点を整える範囲で十分なことが多い
- 「派手にする」ことと「個性を出す」ことは別。抑制した個性（静かな精密さ）もある
