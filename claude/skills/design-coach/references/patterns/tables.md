# テーブル・一覧・一括操作

確認状況: NN/g「Data Tables」と Carbon Design System「Data table usage」を取得して内容を確認済み。数値（行の高さ、ツールバーの数）は **Carbon の一例**であり、普遍的な基準ではない。

## 原則

テーブルは「探す・比べる・選ぶ・操作する」ための道具。OOUI では**コレクションビュー**（`ia/ooui.md`）にあたる。

## 適用ルール

### 列と行
- **列の既定順は重要度順**。関連する列は隣り合わせにする（NN/g）
- 先頭列は、**自動生成された分かりにくい ID ではなく、人が読める識別子**（名前、番号など）にする（NN/g）
- 比べたいデータは近くに置く。離れた列や行を比べさせると、記憶と視線の往復が増える（NN/g）
- 列見出しは**1〜2語**。長い場合は2行まで折り返し、それ以上は省略してツールチップで全文（Carbon）
- 列が多すぎると横スクロールが要り、比較が難しくなる（NN/g。推奨列数は示されていない）。列の表示・非表示の切替で調整し、非表示列があることも状態で示す
- 画面より大きいテーブルは、**ヘッダー行と見出し列を固定**する（NN/g）
- 行の区別に、罫線・ゼブラストライプ・ホバー時のハイライトを使う。**行ホバーは、クリックできない行でも有効にする**（目で横を追うため。Carbon）
- 数値は右揃え、文字は左揃え、見出しは対応する列と同じ揃え（経験則。NN/g の記事には記載なし）

### ソート・フィルタ・検索
- **ソートとフィルタは別機能**として扱う（NN/g）
- ソートは列見出しで切替。状態は3つ（未ソート / 昇順 / 降順）。ソート中の列のアイコンは常時表示し、未ソート列はホバー時のみ表示（Carbon）
- フィルタは、見つけやすく、素早く使え、強力であること。**有効なフィルタがあることを視覚的に明示**する（NN/g）
- 詳細は `patterns/search-filter.md`

### 行の高さ（Carbon の例）

| サイズ | 高さ | 用途 |
|--------|------|------|
| xs | 24px | 非常に高密度 |
| sm | 32px | コンパクト |
| md | 40px | 既定。最もよく使う |
| lg | 48px | ゆったり、操作しやすさ重視 |
| xl | 64px | 1行に複数行の情報があるとき |

ユーザーが密度を切り替えられるとよい（経験則）。

### ツールバーと一括操作（バッチアクション）
- ツールバーには、グローバルな操作（主ボタン、検索、フィルタ、表示設定、エクスポートなど）を置く。**アクションは最大5つ**まで。超える分はオーバーフローメニューにまとめる（Carbon）
- 行を選択すると、テーブル上部に**バッチアクションバー**が現れ、選択全体に操作を適用する（Carbon）
- バッチモード中は、行ごとの単一操作アイコンとオーバーフローメニューを**無効化**する（Carbon）。終了はキャンセルボタン、または全選択解除
- 行のチェックボックスは**2状態**（オン / オフ）、ヘッダーの全選択は**3状態**（オン / オフ / 一部選択）（Carbon）
- 行内のアクションが**3つ未満**なら、メニューにせずアイコンボタンで並べる（Carbon）
- 複数件を一度に操作する場面は、タスク指向が許容される典型（`ia/task-vs-object.md`）。**破壊的な一括操作には、件数を示した確認、または Undo** を用意する（`patterns/errors-undo.md`）

### ページングとロード
- ページングは常にテーブルの下。**シンプル型**（前後移動のみ）と**詳細型**（件数変更、ページ指定）がある（Carbon）
- 読み込みに時間がかかるときは、スピナーよりも**スケルトン**表示（Carbon）
- 0件・検索結果なし・エラーは `patterns/empty-states.md`

## 失敗例

- 先頭列が UUID や連番で、何の行か分からない
- ソートとフィルタが混在し、いまの絞り込み状態が分からない
- 有効なフィルタが見えず、「データが消えた」と誤解される
- 一括削除に確認も Undo もない
- 行ごとのアクションが多すぎて、ボタンが横に並ぶ

## チェックリスト

- [ ] 先頭列が人間にとって意味のある識別子
- [ ] 列の順序が重要度順で、関連列が隣り合う
- [ ] ヘッダー固定（大きいテーブル）
- [ ] 有効なフィルタが分かる表示になっている
- [ ] バッチ操作の対象件数が見え、破壊的操作は保護されている
- [ ] 0件・読み込み中・エラーの表示がある
- [ ] 行の密度が用途（一覧の閲覧か、集中的な操作か）に合っている
